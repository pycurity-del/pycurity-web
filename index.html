01 · El problema

La seguridad de las bicicletas es un reto.

El robo de bicicletas afecta la tranquilidad de sus usuarios y puede dificultar el uso de este medio de transporte. Por eso, buscamos explorar cómo la tecnología puede aportar nuevas alternativas de protección.

🚲

Una necesidad real

Los ciclistas necesitan alternativas que ayuden a proteger sus bicicletas durante sus actividades diarias.

🔐

Limitaciones de los métodos tradicionales

Los candados convencionales pueden no ser suficientes en todas las situaciones y lugares.

💡

Una oportunidad tecnológica

La electrónica y los sistemas de control permiten desarrollar nuevas soluciones para complementar la seguridad.

Pregunta de investigación
¿Cómo puede un sistema inteligente basado en ESP32 y sensores contribuir a prevenir el robo de bicicletas y mejorar la percepción de seguridad de sus usuarios?
02 · Nuestra propuesta

Una solución que combina electrónica y control web.

PY-CURITY desarrolla un prototipo de bloqueo electrónico para bicicletas. El sistema utiliza una ESP32 para recibir órdenes desde una interfaz web y controlar el mecanismo de bloqueo.

  • Control electrónico mediante una ESP32.
  • Activación del mecanismo a través de un sistema de control web.
  • Comunicación mediante MQTT y HiveMQ.
  • Uso de un relé para controlar el circuito del electroimán.
1

Solicitud desde la web

El usuario envía una orden desde la interfaz de control.

2

Comunicación

La orden se transmite mediante el sistema de mensajería MQTT.

3

Procesamiento con ESP32

La placa recibe la orden y controla la salida conectada al relé.

4

Acción del mecanismo

El circuito acciona el electroimán para realizar el bloqueo previsto.

03 · Tecnología utilizada

Los componentes del prototipo

Cada elemento cumple una función dentro del sistema de control electrónico desarrollado por el equipo.

🧠

ESP32

Es la unidad de control que recibe las instrucciones y administra las señales del circuito.

⚡

Relé

Permite controlar el circuito eléctrico del mecanismo a partir de una señal de control.

🔒

Electroimán

Es el mecanismo electromagnético utilizado en el prototipo para realizar la función de bloqueo.

💻

Interfaz web

Permite enviar órdenes al sistema desde una página de control.

📡

MQTT y HiveMQ

Se utilizan para transmitir mensajes entre la página de control y el sistema electrónico.

🔋

Alimentación eléctrica

Proporciona la energía necesaria para los componentes de acuerdo con sus requerimientos eléctricos.

04 · Desarrollo práctico

De la idea al prototipo funcional.

El equipo integró la programación de la ESP32, la comunicación mediante MQTT, el relé y el electroimán para desarrollar un sistema de bloqueo controlado desde una página web.

Durante el desarrollo se realizaron pruebas de comunicación y funcionamiento del mecanismo, ajustando la integración entre los componentes.

🛠️

¿Qué demuestra el prototipo?

  • Integración de hardware y software.
  • Control electrónico de un mecanismo de bloqueo.
  • Comunicación entre una interfaz web y una ESP32.
  • Aplicación de conocimientos tecnológicos a una necesidad real.

El prototipo es una propuesta de apoyo a la seguridad. No garantiza por sí solo la prevención de todos los robos.

05 · Investigación

¿Qué encontramos en la encuesta?

Las respuestas recopiladas ayudan a comprender la preocupación por la seguridad de las bicicletas y la percepción de los métodos de protección tradicionales.

85,4%

Conoce a alguien que sufrió el robo de una bicicleta

La mayoría de las personas encuestadas afirmó conocer a alguien que ha vivido esta situación.

61%

Considera insuficientes los candados tradicionales

Este resultado refleja una percepción favorable a explorar alternativas de seguridad complementarias.

Fuente: encuesta realizada por el equipo de PY-CURITY S.A.S. Se recopilaron 41 respuestas. Los porcentajes se presentan según los resultados compartidos por el equipo.
