01 / El problema

La seguridad de una bicicleta importa.

La bicicleta es un medio de transporte, una herramienta de trabajo y una forma de hacer actividad física. Sin embargo, el riesgo de hurto genera preocupación entre sus usuarios y hace necesario explorar alternativas de protección.

⌕

Una necesidad real

Los métodos tradicionales de seguridad pueden tener limitaciones según el tipo de candado, el lugar y las condiciones en las que se estaciona la bicicleta.

↗

Nuestra pregunta de investigación

¿Cómo puede una solución tecnológica de bloqueo electrónico contribuir a fortalecer la seguridad de las bicicletas?

02 / Nuestra solución

Un sistema de bloqueo con control electrónico.

PY-CURITY integra componentes electrónicos y una interfaz web para enviar una orden de control al prototipo. El objetivo es demostrar cómo la tecnología puede aplicarse a una necesidad cotidiana.

PASO 01

Interfaz web

El usuario interactúa con una página que permite enviar la orden de control.

PASO 02

Mensaje MQTT

La comunicación transmite el mensaje a través del tópico configurado para el proyecto.

PASO 03

ESP32 y relé

La ESP32 recibe la orden y controla el circuito mediante el módulo de relé.

PASO 04

Electroimán

El circuito acciona el electroimán según la configuración del prototipo.

Esta página es explicativa y no está conectada al dispositivo. El prototipo se controla desde la interfaz y el sistema electrónico configurados para la demostración.
03 / El prototipo

Una idea construida y puesta a prueba.

El prototipo reúne una ESP32, un módulo de relé y un electroimán, con control mediante una página web y comunicación MQTT. Durante el desarrollo se integraron el software y los componentes físicos para comprobar el funcionamiento del bloqueo.

Componentes principales

  • ESP32: procesa los mensajes de control.
  • Módulo de relé: conmuta el circuito de carga.
  • Electroimán: elemento de bloqueo del montaje.
  • Interfaz web: permite enviar las órdenes.
  • MQTT: canal de comunicación entre la interfaz y el dispositivo.

04 / Consulta a la comunidad

¿Qué nos dicen las respuestas?

En una encuesta exploratoria realizada a 41 personas se preguntó por la experiencia con el hurto de bicicletas y la percepción de los métodos tradicionales de seguridad.
